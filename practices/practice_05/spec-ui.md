# UI Specification (extract)

Контекст: экран списка задач с полем поиска. Источник данных — CLI `task_cli.py`.

- Экран: список задач; над списком — поле поиска с placeholder «Поиск по названию…», кнопками «Очистить» и «Повторить» (retry), индикатор состояния (loading/error).
- Действия пользователя: ввод запроса → через debounce выполняется поиск; ESC/кнопка «Очистить» снимают поиск и возвращают исходный список; retry повторяет последний запрос.
- Состояния:
  - loading: отображается индикатор во время выполнения поиска.
  - empty: текст «Нет задач по запросу “{запрос}”».
  - error: «Не удалось выполнить поиск», доступна кнопка «Повторить».
- Ошибки: пустой запрос не отправляется; длина >256 — локальная валидация с сообщением.
- Ожидаемое поведение: поиск регистронезависимый contains; поиск накладывается поверх активного фильтра статуса и сохраняет текущую сортировку.

Согласовано на основе `specs/001-task-search-by-name/spec.md` и `.../COMMON_CONTRACT.md`.
