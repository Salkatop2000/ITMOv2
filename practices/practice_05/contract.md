# Общий контракт (UI ↔ Logic)

- Вход: `query` — строка после trim длиной 1..256; пустой query не инициирует `search`.
- Фильтры: `status` (open|done|all); поиск накладывается поверх активных фильтров; сортировка сохраняется на UI.
- Сопоставление: регистронезависимое contains по `title`; спецсимволы — литералы; без regex/stemming.
- Выход: список задач `{ id, title, status }` в порядке текущего листинга; при отсутствии результатов — «No tasks.».
- Ошибки: слишком длинный запрос — валидационная ошибка; системные ошибки отображаются на UI с возможностью `Retry`.
- Поведение очистки: кнопка «Очистить» и ESC очищают поле, UI возвращает исходный список без вызова `search` с пустой строкой.

Источник: `specs/001-task-search-by-name/COMMON_CONTRACT.md` и `RECONCILIATION.md` (раздел Human Reconciliation — Approved).
