Трекер задач (CLI)

Назначение

Простой локальный CLI для управления небольшим списком задач, хранящимся в JSON-файле. Проект подготовлен как минимальная и чистая база для последующих демонстраций автоматизации с OpenCode (на данном этапе нет skills/MCP/hooks).

Структура

- src/task_cli.py: реализация CLI (хелперы хранения, операции над задачами, обработка команд)
- tests/test_task_cli.py: тесты на pytest
- data/tasks.json: локальное хранилище JSON (начальное содержимое — [])
- scripts/check.sh: воспроизводимый runner для тестов и smoke-проверок
- README.md: этот файл
- .gitignore: стандартные исключения

Формат данных

Файл data/tasks.json содержит список объектов:

[
  { "id": 1, "title": "Подготовить отчёт", "status": "open" }
]

status принимает значения open или done.

Использование CLI

Все команды принимают опциональный параметр --data PATH для указания альтернативного файла JSON. По умолчанию используется data/tasks.json в корне проекта.

1. Добавление задачи

python src/task_cli.py add "Подготовить отчёт"

Выводит созданную задачу в виде JSON одной строкой, назначает автоинкрементный id и статус open.

2. Просмотр задач

python src/task_cli.py list
python src/task_cli.py list --status open
python src/task_cli.py list --status done

3. Завершение задачи

python src/task_cli.py done 1

Если задача не найдена, процесс завершается с ненулевым кодом и сообщением в stderr. Повторная попытка завершить уже выполненную задачу выводит понятное сообщение и завершается с кодом 0.

4. Очистка задач

Удаление задач по статусу. По умолчанию удаляются выполненные (done). Доступны варианты open, done, all.

python src/task_cli.py clear --status done
python src/task_cli.py clear --status open
python src/task_cli.py clear --status all

Команда печатает количество удалённых задач.

Тесты

При наличии pytest запустите:

pytest -q

Runner

scripts/check.sh выполняет воспроизводимые базовые проверки:

1. Переходит в корень проекта
2. Запускает pytest (если доступен)
3. Выполняет smoke-проверки CLI: add, list, done

Запуск:

bash scripts/check.sh

Примечания

Проект намеренно не использует базы данных, серверы, контейнеры или внешние интеграции. Это минимальная основа для будущих демонстраций инструментов автоматизации.
