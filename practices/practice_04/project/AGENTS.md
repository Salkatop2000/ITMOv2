Правила работы

- Область: Работайте только внутри каталога проекта (practices/practice_04/project).
- После любого изменения кода запускайте scripts/check.sh для проверки тестов и "дымового" запуска CLI.
- Навыки: Загружайте навык gui-app только при явной просьбе добавить GUI (ключевые слова: Tkinter/PySimpleGUI/Qt).
- MCP: Используйте инструмент task-cli MCP для подсчета задач из data/tasks.json или указанного пути.
- Инструменты: Предпочитайте glob/grep/read вместо разовых shell-команд для поиска/чтения. Bash используйте экономно.

Обоснование

- Связь с навыком: gui-app ограничивает изменения GUI минимальным обертчиком Tkinter над src/task_cli.py.
- Связь с MCP: task-cli MCP обеспечивает безопасный, только для чтения, подсчет задач через JSON-RPC, избегая прямого парсинга файлов в подсказках. Упоминается реальный MCP на базе официальной Python-библиотеки.
- Связь с плагином: плагин auto-check запускает scripts/check.sh после успешных правок, чтобы раннее поймать регрессии.

Изменения

- Файл переведен на русский язык и уточнены упоминания о реальном MCP (официальная Python-библиотека).
